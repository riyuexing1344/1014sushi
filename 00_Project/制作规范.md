# 制作规范

> 版本：v1 · 2026-10-14
> 本文件是全系列的技术基准。**定稿后不得中途更改**，否则各集风格不统一。

---

## 一、视觉风格基准

### 1.1 风格定义（全集唯一，绝不更换）

```
宋代工笔 2D 古风动画，水墨淡彩，宋代古画质感，
柔和自然光，线条简练，淡墨晕染，留白，色彩淡雅。
```

### 1.2 为什么不用真人写实

1. **一致性容错率**：写实人脸差一点就"不是同一个人"；工笔/水墨靠造型符号（头巾、须型、衣纹）识别角色，容错高一个数量级
2. **恐怖谷**：AI 生成的写实古人大概率油腻、塑料感
3. **考据成本**：写实风格下任何服饰、建筑、器物错误都会被放大；绘画风格天然有"艺术处理"豁免

## 二、技术参数

| 项 | 值 |
|---|---|
| 画幅 | 9:16 竖屏 |
| 分辨率 | 1080 × 1920 |
| 帧率 | 30 fps |
| 编码 | H.264 |
| 容器 | MP4 |
| 单片段时长 | 3-7 秒，**推荐 5 秒** |
| 单集时长 | 90 秒（试点与前 3 集） |
| 旁白语速 | 约 4 字/秒（90 秒 ≈ 240 字） |

## 三、画面硬约束

| 约束 | 说明 |
|---|---|
| **时代** | 一切器物、建筑、服饰限定北宋（960-1127） |
| **不在画面内生成中文** | AI 写不对汉字。诗词和字幕一律后期添加 |
| **风格单一** | 全集只用一套风格提示词 |
| **正脸特写配额** | 每集 ≤ 5 个 |
| **单镜头动作数** | 1 个主要动作 + 1 个镜头运动，不堆叠 |

### 3.1 构图策略：多用低风险景别

AI 画远景、背影、侧影、剪影、局部特写时，角色一致性压力极小，
而水墨风格里这些镜头反而最有意境。

**优先级：远景 / 背影 / 剪影 > 侧影 / 中景 > 正脸特写**

## 四、固定负面提示词

每次生成画面都必须带上：

```
现代服装，现代建筑，手机，电线，汽车，塑料制品，
明清家具，明清服饰，唐代服饰，日式和服，韩服，
畸形人脸，五官扭曲，多只手，多手指，断肢，扭曲肢体，
文字，水印，字幕，签名，Logo，
低画质，模糊，过曝，噪点，
二次元夸张，卡通变形，仙侠华丽装饰，发光特效
```

## 五、常见穿帮自查

| 类别 | 北宋正确 | 要避开的错误 |
|---|---|---|
| 椅子 | 已有高足家具，形制朴素 | 明式圈椅、清式太师椅 |
| 桌案 | 素面，线条简洁 | 明清雕花 |
| 器皿 | 宋瓷素雅（青白瓷、建盏） | 明清青花、珐琅彩 |
| 书籍 | 线装 / 蝴蝶装 | 现代精装书 |
| 窗 | 木格窗、纸窗 | 玻璃 |

## 六、音频规范

| 项 | 规范 |
|---|---|
| 旁白音色 | 温润中年男声，沉稳，历史纪录片质感 |
| 参考音色 | `zh-CN-YunxiNeural`、`zh-CN-YunzeNeural` |
| 语速 | 0.9 |
| BGM | 古琴、箫、埙、琵琶类；一集一首铺底 |
| **音量规则** | **BGM 必须明显低于旁白** |
| 必备音效 | 雨声、江水、马蹄、翻书、脚步（最易被忽略，但加上质感提升明显） |

## 七、文件命名规则

| 类型 | 格式 | 示例 |
|---|---|---|
| 分镜静帧 | `S{两位编号}.png` | `S01.png`、`S16.png` |
| 视频片段 | `S{两位编号}.mp4` | `S09.mp4` |
| 角色参考图 | `{角色}_{阶段}_master.png` | `sushi_huangzhou_master.png` |
| 旁白音频 | `旁白_{集标识}.mp3` | `旁白_PILOT.mp3` |
| 成片 | `{集标识}_v{版本}.mp4` | `EP01_v1.mp4` |

集标识：试点用 `PILOT`，主线用 `EP01`-`EP12`，专题用 `SP-A`-`SP-E`。

## 八、版本与保护规则

1. 已审核的剧本、人物设定、本制作规范**不允许 AI 随意覆盖**
2. 修改保留版本：`旁白稿_v1.md` → `旁白稿_v2.md`
3. 记录修改原因与审核状态
4. 每个镜头保留：提示词 + 参考图 + 生成结果 + 返工原因
5. 不确定的历史细节进**待核实清单**，不得悄悄写进正式剧本
