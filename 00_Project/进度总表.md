## 一、九阶段流水线

```
Phase 0  立项      定风格/时长/集数/目录结构
Phase 1  史料      事实卡片表 + 核查
Phase 2  剧本      旁白文案定稿
Phase 3  角色      角色设定卡 + 主参考图      ← 单独验收
Phase 4  分镜      分镜表（含正/负提示词）
Phase 5  配音      先出音频！                 ← 铁律
Phase 6  出图      静态分镜图（先出 3 张测试）
Phase 7  生视频    图生视频，5 秒/片段
Phase 8  合成      剪辑、字幕、BGM、音效、导出
Phase 9  验收      对照清单逐项检查 + 复盘归档
```

### 三条顺序铁律

1. **Phase 5 先于 Phase 6** —— 用旁白实际时长决定镜头秒数
2. **Phase 3 必须单独验收** —— 角色没定死就开工，做到第 10 镜发现人变了，前面全废
3. **Phase 6 先出 3 张测试图** —— 风格没确认就批量出图 = 烧额度
