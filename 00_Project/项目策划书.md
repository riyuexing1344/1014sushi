## 一、项目定义

| 项 | 内容 |
|---|---|
| 系列名 | 《苏轼的一生》 |
| 体裁 | 宋代工笔 2D 古风动画历史短片 |
| 规模 | 主线 12 集 + 专题 5 集，共 17 集 |
| 单集时长 | 试点与前 3 集 90 秒；流程稳定后主线扩至 3-5 分钟，专题保持 90-120 秒 |
| 画幅 | 9:16 竖屏，1080×1920，30fps，H.264 |
| 发布平台 | 抖音、视频号、快手 |
| 制作人水平 | AI 使用初学者 |
| 预算倾向 | 优先免费额度，验证效果后再决定是否付费 |

## 二、内容范围

1. 苏轼的成长、科举、仕途、贬谪与晚年
2. 与苏洵、苏辙、王弗、王闰之、王朝云的亲情与情感
3. 与欧阳修、王安石、司马光、黄庭坚、章惇的交往与冲突
4. 饮食、居住、出行等日常生活（衣食住行）
5. 诗词创作及其历史背景

## 三、工具分工

**WorkBuddy 的角色是"导演 + 制片 + 剪辑助理"，不是"画面生成引擎"。**

| 环节 | 主力 | 备选 / 升级 |
|---|---|---|
| 策划、史料、剧本、分镜、提示词、文件管理 | WorkBuddy | — |
| 人物定妆图、分镜静帧 | WorkBuddy ImageGen | 即梦、Midjourney、Nano Banana |
| 图生视频 | WorkBuddy VideoGen | 可灵（Kling）、Runway |
| 配音 | edge-tts（免费，可脚本批量调用） | 豆包、讯飞；或自己录音 |
| 剪辑、字幕、BGM | 剪映桌面版 | DaVinci Resolve 免费版 |
| 批量合成 | ffmpeg（让 WorkBuddy 写命令） | — |

> ⚠️ WorkBuddy 的实际能力取决于版本、账号权限、已启用工具和额度。开工前先在自己账号里核对：功能是否可用、额度多少、导出有无限制、授权条款如何。

## 四、七个前置决策（已定稿）

| # | 决策项 | 定稿值 | 关键理由 |
|---|---|---|---|
| 1 | 视觉风格 | 宋代工笔 / 水墨淡彩 2D | 一致性容错率高一个数量级，避开恐怖谷 |
| 2 | 叙事形态 | 旁白驱动，角色不对口型 | 绕开 lip-sync；单一旁白音色贯穿全片 |
| 3 | 单集时长 | 试点与前 3 集 90s | ≈240 字旁白 ≈12-16 镜头，可一周完成 |
| 4 | 规模 | 12 主线 + 5 专题 | 覆盖完整人生且每集有独立戏剧核心 |
| 5 | 画幅 | 9:16 / 1080×1920 / 30fps / H.264 | 三平台主流规格 |
| 6 | 首发顺序 | 试点《定风波》→ EP01 眉山少年 → 按序 | 试点用来学流程，不占正片门面 |
| 7 | 工作流铁律 | 配音（Phase 5）先于出图（Phase 6） | 旁白实际时长决定镜头秒数 |

> 决策依据与四源分歧裁决过程见总纲第 0.2 节。**改动任一项需重新评估全案。**

## 六、制作原则

1. 先研究史实，再编剧
2. 每集先出剧本和分镜，**人工确认后**才进入视频生成
3. 明确区分【确定史实】【合理推演】【民间传说】
4. 不确定的内容标注"待核实"，不得编造来源
5. 角色在不同集数中保持面貌、年龄、服饰、性格一致
6. 优先使用免费或低成本工具
7. **先做一个 90 秒试点片段跑通全链路，再批量制作**

## 七、成功标准

**第一阶段**（本阶段）：完成《定风波》90 秒试点，验证角色一致性、氛围控制、运镜、旁白、诗词呈现五项。

**第二阶段**：完成 EP01 并发布，建立可复用的人物卡与风格模板。

**第三阶段**：连续完成 3 集后，将稳定、重复、耗时的步骤固化为 WorkBuddy 任务模板。

> 不要一开始就开发复杂自动化。先通过实际制作找出瓶颈，再考虑自动化。
