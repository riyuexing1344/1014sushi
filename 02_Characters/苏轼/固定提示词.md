## 一、黄州中年（45 岁）· 试点与 EP08 使用

### 基准段（原样复制）

```
宋代工笔 2D 古风动画风格，水墨淡彩，宋代古画质感。
人物：苏轼，四十五岁，北宋文人。
面部：长方脸，颧骨略高，浓眉，眼神温和带笑意。
须发：蓄及胸长须，黑中带灰；束发，裹黑色头巾（东坡巾）。
服饰：青灰色粗布直裰，腰束布带，无纹饰。
体态：身形清癯，中等偏高。
画面：柔和自然光，线条简练，淡墨晕染，留白，色彩淡雅，无边框，无文字。
```

```
场景：【江岸田间小路 / 雨中竹林 / 荒田 / 山头斜照】
景别：【大远景 / 远景 / 中景 / 特写 / 背影 / 侧影 / 剪影】

动作：【拄竹杖缓行 / 驻足回望 / 仰面迎雨 / 手指远方】
画幅：9:16 竖屏
```

## 五、图生视频提示词模板

```
以提供的静态分镜图作为唯一视觉参考，
保持人物面部、须发、服饰、场景和光线完全一致。

人物只执行一个自然、缓慢的动作：【具体动作】
镜头只做一种运动：【缓推 / 缓拉 / 横移 / 固定】

画面保持宋代工笔动画风格，动作连贯不夸张。
不改变人物年龄和五官，不增加其他人物，
不出现现代物品，不生成字幕和文字。

时长 5 秒，9:16 竖屏。
```

### 动作示例（每次只换这一句）

- 人物低头阅读，右手轻轻翻过一页书卷
- 窗外树叶轻微摆动，人物保持安静，镜头缓慢推进
- 人物从田埂上缓步走过，镜头从侧后方平稳跟随
- 雨滴落在竹叶上，人物衣袖被风轻轻吹起
- 人物驻足回望，仅头部缓慢转动

> ⚠️ **不要在一个镜头里同时要求**：走路 + 转身 + 说话 + 拿东西 + 大幅运镜。
> 初学阶段动作越少，可用率越高。

## 六、使用检查表

每次生成前确认：

- [ ] 粘贴了完整基准段（不是记忆中的简写）
- [ ] 粘贴了负面提示词
- [ ] 指定了画幅 9:16
- [ ] 单镜头只有 1 个动作 + 1 个运镜
- [ ] 引用了主参考图（如工具支持）

每次生成后检查：

- [ ] 脸型、颧骨、眉形是否与主参考图一致
- [ ] 须的长度与颜色是否正确（不同阶段不同）
- [ ] 头巾/服饰是否正确
- [ ] 有无现代物品、明清器物
- [ ] 画面内有无乱码文字
