# 验收清单模板

> 用法：每集复制一份，命名为 `{集标识}_验收记录.md`，逐项打勾
> 来源：总纲第 11 节

---

## Phase 1 · 史料验收

- [ ] 事实卡片表已建立，覆盖本集全部情节
- [ ] 重要事件有可追溯来源（能自己复查到原文，不只信 AI 的说法）
- [ ] 已区分 ✅ 史实 / ⚠️ 传说 / ❓ 待核实
- [ ] 有争议的说法已标记
- [ ] 文件**实际保存在目录中**（去磁盘确认，不信对话输出）

## Phase 2 · 剧本验收

- [ ] **每条旁白可对应事实卡片某一行**（逐句核验表已填）
- [ ] 史实 / 推演 / 传说已明确区分，传说处措辞留有余地
- [ ] 实际朗读并计时，符合目标时长
- [ ] 本集只表达一个主要观点，没有信息过载
- [ ] 诗词原文无错字、断句正确
- [ ] 开头 3 秒有钩子
- [ ] 结尾有引向下一集的钩子

## Phase 3 · 角色验收（**单独验收，不可跳过**）

- [ ] 主参考图已选定并按命名规则存档
- [ ] 固定提示词已成文，可直接复制
- [ ] 生成参数（工具、完整提示词、seed）已记录
- [ ] 三个年龄段形象**差异清晰但可辨为同一人**（脸型、颧骨、眉形贯穿）
- [ ] 服饰符合北宋与人物当时身份
- [ ] 本集涉及的配角设定卡已就绪

> ⚠️ 角色没定死就开工，做到第 10 个镜头发现人变了，前面全废。

## Phase 4 · 分镜验收

- [ ] 镜头时长之和匹配目标时长
- [ ] 单镜头 3-7 秒，无超长镜头
- [ ] 单镜头只有 1 个主要动作 + 1 个镜头运动
- [ ] 正脸特写 ≤ 5 个
- [ ] 高风险镜头已标记并有降级方案
- [ ] 每镜都有图像提示词和视频提示词
- [ ] 画面内不含需要 AI 生成的中文

## Phase 5 · 配音验收

- [ ] 音色符合规范（温润中年男声，无广告腔）
- [ ] **实际时长已计时**并回头调整了分镜秒数
- [ ] 诗词句的吟诵感与叙述段落有层次区分
- [ ] 停顿与重音符合情绪标记
- [ ] 无错字、无读音错误

> ⚠️ **铁律：本阶段必须在 Phase 6 之前完成。**

## Phase 6 · 静态图验收

- [ ] **先出 3 张测试图确认风格**，再批量生成
- [ ] 人物符合固定角色设定（脸型、须、头巾、服饰、体型五项）
- [ ] 服装发式符合本集时代与身份
- [ ] 9:16 构图正确
- [ ] 无现代物品、明清器物、乱码文字、水印
- [ ] 场景适合后续做动态
- [ ] 无不必要的复杂人物或动作

## Phase 7 · 视频验收

- [ ] 每段引用了对应静态图作为参考
- [ ] 单片段 ≤ 7 秒
- [ ] 人物面貌在运动中未发生改变
- [ ] 无肢体畸形、多指、穿模
- [ ] 动作自然不夸张
- [ ] 失败片段已记录原因（便于复盘）

## Phase 8 · 合成验收

- [ ] 按分镜顺序排列正确
- [ ] 画面与旁白语义对齐
- [ ] 静态图已加缓慢推拉/平移，无完全静止画面
- [ ] 字幕准确，错字已校对，时间轴对齐
- [ ] **BGM 音量明显低于旁白**
- [ ] 音效已添加（雨/风/脚步等）
- [ ] 转场简单统一（淡入淡出即可）

## Phase 9 · 成片验收

- [ ] 核心史实、人物关系、年代已核实
- [ ] 主要人物面貌、服装、年龄**全片一致**
- [ ] 镜头间能连贯讲一个故事
- [ ] 旁白清楚，无错字与发音错误
- [ ] 无明显穿帮、变脸、肢体异常
- [ ] 时长、画幅、清晰度符合发布要求
- [ ] 从头到尾看两遍：一遍查故事，一遍查技术
- [ ] 剪辑工程、成片、本验收记录均已归档

### 发布前合规检查

- [ ] 图像/视频生成工具输出**允许商用**（免费试用 ≠ 可免费商用）
- [ ] BGM 授权覆盖目标平台
- [ ] 音效来源与授权已确认
- [ ] **字体可商用**（片头片尾题字最容易踩坑，很多书法字体需授权）
- [ ] 每项素材的来源、授权条件、下载日期已记录
- [ ] 已跑敏感词检查
- [ ] 历史人物评价保持中性

---

## 优先级原则

> **历史准确性 > 画面华丽。**
> **人物一致性和叙事连贯性决定观众是否追看。**
